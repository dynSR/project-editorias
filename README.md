# Editorias

Editorias is a collection of editor tools and utilities focused on the EditorGUILayout API wrapping/overloading for Unity.
It provides a set of commonly used editor GUI elements and functionalities to streamline the development process in Unity.

## Features

- Custom EditorGUILayout wrappers for enhanced functionality and ease of use.
- A variety of editor tools to assist with common tasks in Unity development.
- Improved workflow and efficiency when creating custom editor windows and inspectors.
